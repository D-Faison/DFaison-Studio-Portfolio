# DFaison_FullStack_ProfessionalPortfolio26

A polished single-page portfolio for a full stack developer and 3D artist.

## Included sections
- Hero section
- About me with education highlights
- Toolbox with front end, design, and back end tools
- Full stack project cards with GitHub links
- 3D art gallery slideshow

## Preview locally
Open the site in a browser at:
- http://127.0.0.1:8000/index.html

## Publish to GitHub Pages
1. Create a new GitHub repository and upload these files.
2. In the repository settings, open Pages.
3. Choose the main branch and the root folder.
4. Save and wait for the live URL.
